Invoice Brand Selector

Manage multiple commercial brands on a single Odoo instance.
Select the brand per invoice — PDF adapts automatically.

Odoo 19 Community Enterprise OPL-1 Invoicing

🎯 Use Case

Perfect for companies that operate under multiple commercial brands but share the same legal entity, Tax ID and accounting.

Example: A company with brands Framarketing and Romatel needs invoices with the correct logo and contact info per brand — without changing company settings every time.

✨ Features

🖼️ Logo per brand Upload a different logo for each commercial brand.
🎨 Dynamic colors Primary color for table headers adapts per brand.
📧 Custom footer Email, website, phone and Tax ID per brand in the PDF footer.
♾️ Unlimited brands Create as many commercial brands as you need.
🔒 Access control Managers configure brands. Users just select on invoices.
🌍 Multilingual Includes Spanish (es) translation out of the box.

🚀 How it works

Go to Invoicing → Configuration → Commercial Brands and create your brands with logo, colors and contact info.
Open any customer invoice and select the Commercial Brand from the dropdown field.
Print or send the invoice — the PDF is automatically generated with the selected brand's logo and footer.

⚙️ Configuration

Each brand profile includes:

  • Logo — uploaded directly in Odoo
  • Primary color — hex color picker for table headers
  • Email, Website, Phone, Tax ID — shown in PDF footer
  • Custom footer text — override with free text if needed

📋 Requirements

  • Odoo 19.0 (Community or Enterprise)
  • Invoicing (account) module
  • Bubble layout recommended
