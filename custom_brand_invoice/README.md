# Invoice Brand Selector

**Manage multiple commercial brands on customer invoices.**

## Use Case

Perfect for companies operating under multiple commercial brands
but sharing the same legal entity and accounting (same Tax ID).

## Features

- Unlimited commercial brands
- Per-brand: logo, primary color, email, website, phone, Tax ID
- Custom or auto-built PDF footer per brand
- Brand selector on every customer invoice
- Dynamic PDF: logo + footer change automatically
- Role-based access: managers configure, users select
- Compatible with Odoo Bubble layout

## Installation

1. Copy `invoice_brand_selector` to your Odoo addons path
2. Restart Odoo server
3. Enable Developer Mode → Apps → Update App List
4. Search "Invoice Brand Selector" → Install

## Configuration

Go to **Invoicing → Configuration → Commercial Brands** and create your brands.

## Usage

Open any customer invoice → select **Commercial Brand** → print PDF.

## Compatibility

- Odoo 19.0 Community & Enterprise
- Requires: account module
